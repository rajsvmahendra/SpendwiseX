## 🌟 Overview

**SpendWise X** is a personal financial intelligence platform that transforms how people relate to their money. Instead of forcing users to fill out tedious forms, it lets them type expenses the way they'd naturally speak — *"500 at Zomato yesterday"* — and instantly organizes, analyzes, and visualizes their spending.

Most expense trackers stop at showing you numbers. SpendWise X goes further: it interprets patterns, identifies unusual spending, computes a financial health score, and reveals your spending habits through an interactive visualization no other finance app has attempted.

Built as a premium product experience — not another admin dashboard — SpendWise X answers questions like:

- *How am I doing this month?*
- *What changed since last week?*
- *What deserves my attention today?*
- *Where is my money really going?*
- *What patterns haven't I noticed?*

Every interaction is designed to make personal finance feel **calm, insightful, and human**.

## ⚙️ Installation

### Prerequisites

- **Python 3.9** or higher
- **pip** (Python package installer)
- A modern web browser (Chrome, Firefox, Safari, Edge)

### Step-by-Step Setup

<details>
<summary><b>1. Clone the repository</b></summary>

```bash
git clone https://github.com/rajsvmahendra/SpendWise.git
cd SpendWise
```

</details>

<details>
<summary><b>2. Create a virtual environment</b></summary>

```bash
# macOS / Linux
python3 -m venv venv
source venv/bin/activate

# Windows
python -m venv venv
venv\Scripts\activate
```

</details>

<details>
<summary><b>3. Install dependencies</b></summary>

```bash
pip install -r requirements.txt
```

</details>

<details>
<summary><b>4. Initialize the database</b></summary>

The database is created automatically on first run. If you need to reset:

```bash
rm data/spendwise.db
python app.py
```

</details>

## 🔐 Environment Variables

Create a `.env` file in the project root:

```env
# Flask Configuration
FLASK_APP=app.py
FLASK_ENV=development
SECRET_KEY=your-secret-key-here

# Database
DATABASE_PATH=data/spendwise.db

# Optional: AI Service (for enhanced NLP in future versions)
# AI_API_KEY=your-api-key
```

> **Note:** SpendWise X currently uses a rule-based NLP parser that works entirely offline. No external API keys are required for core functionality.

## 🤖 AI Workflow

SpendWise X uses a **transparent, rule-based natural language processing pipeline** designed to feel invisible to the user while remaining fully explainable.

### How It Works

```
User types: "500 at zomato yesterday"
        │
        ▼
┌──────────────────────────────────────────────────┐
│  1. INPUT LAYER                                   │
│     Raw text captured with 400ms debounce         │
└──────────────────────┬───────────────────────────┘
                       │
                       ▼
┌──────────────────────────────────────────────────┐
│  2. TOKENIZATION                                  │
│     Extract candidate entities:                   │
│     • Numbers → potential amounts                 │
│     • Merchant keywords → business names          │
│     • Date phrases → temporal references          │
│     • Category hints → spending type              │
└──────────────────────┬───────────────────────────┘
                       │
                       ▼
┌──────────────────────────────────────────────────┐
│  3. ENTITY RECOGNITION                            │
│     Assign each token to a semantic role:         │
│     • amount: 500                                 │
│     • merchant: "zomato"                          │
│     • date: yesterday → 2024-11-XX                │
│     • category: inferred as "Restaurants"         │
└──────────────────────┬───────────────────────────┘
                       │
                       ▼
┌──────────────────────────────────────────────────┐
│  4. CONFIDENCE SCORING                            │
│     Each extracted field gets a confidence rating:│
│     • high    → explicit and unambiguous          │
│     • medium  → inferred with context             │
│     • low     → best guess, needs review          │
│     • none    → not detected                      │
└──────────────────────┬───────────────────────────┘
                       │
                       ▼
┌──────────────────────────────────────────────────┐
│  5. RESPONSE                                      │
│     JSON returned to frontend:                    │
│     • Populates receipt preview card              │
│     • Fills token chips below input               │
│     • Auto-fills manual form                      │
│     • Triggers confidence indicator               │
└──────────────────────────────────────────────────┘
```

### Why This Approach?

- **Fast** — no external API calls, responses in milliseconds
- **Private** — all processing happens on your server
- **Explainable** — every decision is traceable
- **Reliable** — works offline, no dependency risks

## 🎨 Design Philosophy

SpendWise X was built on a single principle:

> **Personal finance should feel calm, not clinical.**

Most financial apps overwhelm users with data, colors, and controls. SpendWise X takes the opposite approach.

### Core Design Principles

<table>
<tr>
<td width="33%">

**🌊 Atmospheric, Not Decorative**

Every visual layer serves a purpose. Ambient light, subtle textures, and depth are used to create presence — not to impress.

</td>
<td width="33%">

**🧘 One Question Per Section**

Every part of the interface answers exactly one question. If a section can't be summarized in a single sentence, it's redesigned.

</td>
<td width="33%">

**⚡ Invisible AI**

The AI never announces itself. No "AI is thinking" indicators. No branding badges. The interface simply understands what the user meant.

</td>
</tr>
<tr>
<td>

**💚 Emerald as Meaning**

Emerald is the color of money, growth, and success. It's reserved for moments that genuinely matter — not decoration.

</td>
<td>

**🎯 Progressive Disclosure**

Information reveals itself when needed. The dashboard doesn't dump everything at once — it invites you to explore.

</td>
<td>

**✨ Signature Moments**

The Spending Constellation exists for a single reason: to create one memorable, screenshot-worthy moment that no other finance app offers.

</td>
</tr>
</table>

### The Visual Language

- **Charcoal foundation** — deep, calm, and easy on the eyes for extended sessions
- **Cool grays for text** — modern, precise, professional
- **Emerald for brand & success** — the primary accent that signals "your money"
- **Cyan for AI moments** — visually distinct from user actions
- **Space Grotesk typography** — geometric, contemporary, distinctive
- **JetBrains Mono for numbers** — perfect tabular alignment for financial data

Contributions make the open-source community an incredible place to learn and build. Any contributions you make are **greatly appreciated**.
